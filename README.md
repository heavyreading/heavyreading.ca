# site/ — private draft scaffold

Single-page static site: the WCSB storage/egress monitor, first panel of the
future wcsbdesk.com dashboard. No build step, no external dependencies, inline
CSS, phone-first. Open `index.html` directly in a browser.

## Files

- `index.html` — the page. Five panels: current snapshot, utilization history +
  projection, egress stress by route, 2018 episode timeline, structure proxy.
  (Panel 6, actionable ideas, is staged: data file `../ideas.json` + human
  readout `../ideas.md`, generated by `../prototype/ideas.py`. Wire it up as
  `#panel-ideas` when placing — suggested id, not yet in the HTML.)
  Charts load from `../prototype/charts/` (stable filenames); each chart has a
  graceful placeholder if the PNG is not there yet.

## Licensed-data gating

Sections containing licensed data carry `data-licensed` attributes
(`wood-mackenzie` or `eikon`). Append `?public=1` to hide them all, or delete
the marked `<section>` blocks. The full mapping is in the comment at the top of
`index.html`. Public-safe section: egress (CER data).
